## 为什么是这个顺序

01 和 02 是要**读透**的,03 04 05 是**工具书**。

很多人一上来读《三命通会》,60 万字全是神煞歌诀,读完什么也没学会——因为它本来就不是教材,是词典。

正确路径:**先用 01 建立「月令取用神」这一套框架,再用 02 学会权衡强弱**。这两本吃透,八字就通了,剩下三本自然会用。
