## 第二步 · 我的判断

### 2.1 强弱

| 项 | 我的判断 | 依据 |
|---|---|---|
| **旺 / 衰** | **衰** | 乙木生酉月,金当令,木失令 |
| **强 / 弱** | **偏弱但不算无根** | 见下 |
| 四字合并 | **衰而略强** | 失时,但有印有根 |
| 日主的根 | 未中藏乙(余气,1×1.0)、亥中藏甲(中气,约 1.5) | 总分约 2.5,轻根 |

**对方力量**:辛×2(天干)、酉×2(地支,月支×1.5)→ 官杀极重,约 7 分以上。

**结论**:杀重身轻。

> 复盘时注意:我这里差点把「失令」直接判成「身弱到底」——**幸好按第 11 章先分了旺衰强弱**,才发现印有根。

### 2.2 有没有走极端

- [x] 考虑过从格 → **不从**
  - 理由:年干癸水(印)、时支亥水(壬禄,印通根)。**第 13 章:印有根,一律不从。**
  - 而且乙是阴干,「五阴从势」看似该从,但**「印绶有根,则又不嫌身弱」**,例外条款正好命中。
- [ ] 专旺:不考虑(日主不强)

> **这一步是全盘最关键的分叉。** 判从 vs 判不从,喜忌全反。

### 2.3 格局

| 项 | 我的判断 |
|---|---|
| **月令十神** | 酉中辛金,克乙木,阴克阴 → **七杀** |
| **格** | **七杀格** |
| 顺 / 逆 | **凶神逆用** —— 制它或化它 |
| **相神是谁** | **癸水 + 亥水(印)** —— 化杀生身 |
| **成 / 败** | **成**。杀重但有印化 |
| 救应 | 不需要 |
| **格局高低** | **上格偏中** |

**高低理由**:
- **有情**:印在年干,亥在时支,一头一尾;杀在月日紧贴日主。印化杀的通道**不算最贴**,扣分
- **有力**:印有根(亥),杀极有力。加分
- 时干丁火克辛金,**多一条制杀的路**,加分

### 2.4 用神(第 24 章优先级)

| 级 | 检查 | 结论 |
|---|---|---|
| 0 | 专旺 / 从格? | **否**(印有根) |
| 1 | 气候极端? | **否**。酉月不寒不燥;且有丁火 |
| 2 | 格局成立? | **是**。七杀格,印化杀 |
| 3 | 有单一的病? | 无明显单一病神 |
| 4 | 两方僵持? | 杀重身轻,不算势均力敌 |
| 5 | 扶抑? | 不用走到这一级 |

**最终用神**:**印(癸水、亥水)**

**为什么是它不是别的**:
- 停在第 2 级就定了,不必往下走
- 备选是**丁火食伤制杀**(时干丁),但丁坐亥(水),自身无力,且亥水还是印的根 → **制杀这条路弱于化杀**
- 这正是第 15 章说的:**印化杀比食神制杀高明**——「敌人变养分」

**忌神**:
- **财(土)** —— 财生杀、且克印,两头坏
- 燥土尤忌

### 2.5 行运

**最好的运**:**水运、木运**(生印、帮身)
**最凶的运**:**土运**(财旺,生杀破印)
**次凶**:纯金运(杀更重)

## 第三步 · 实际

- **这是谁**:**阎锡山**,民国军政人物,长期主政山西
- **实际**:掌握地方军政大权数十年,是典型的「掌权」型人生
- **徐乐吾原判**:

> 阎锡山造,癸未、辛酉、乙酉、丁亥,**乙木只要有印通根,不怕身弱,煞透有制,即为贵格。**

### 4.2 错在哪

四类都没踩,但有一个**险情**:

**差点归到 B 类(强弱判错)。**

看到「乙木生酉月,满盘金」的第一反应是「从杀」。如果那样判:
- 喜忌全反 → 会说他**喜金土运**
- 而实际他**忌土**
- **一个念头之差,整张喜忌表镜像翻转**

**救我的是第 13 章那条硬规则:先找根后论从,印有根一律不从。**

### 4.3 学到的一条

> **阴干 + 满盘官杀 + 失令,不要凭直觉判从。先把印的根找一遍。**
>
> 徐乐吾专门用阎锡山和许世英两个例子讲这件事,说明这是**高频误判点**,不是偶然。
