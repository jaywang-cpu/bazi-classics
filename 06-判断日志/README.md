# 判断日志

> 从「懂框架」到「能看命」的唯一通道。
>
> [回仓库首页](../README.md)　·　[组合之书](../00-组合之书/README.md)

---

## 为什么要写

**没有反馈的练习不产生能力,只产生错误的自信。**

看八字最大的陷阱是:判断完没人告诉你对不对,于是你永远觉得自己在进步。

这个日志只干一件事:**逼你在看到答案之前,把判断和理由写死。**

写死之后才有对错,有对错才有反馈,有反馈才有能力。

---

## 铁律:先写判断,再看答案

**这是全部的关键,违反了这个日志就没有价值。**

| 正确顺序 | 错误顺序 |
|---|---|
| 只看八字 → 写判断 → 再看这个人是谁/经历 | 先知道是谁 → 再"判断" |

第二种叫**事后归因**,是命理界最普遍的自欺方式。

任何八字,在已知结局之后,都能找出一套说得通的解释。**这不叫准,这叫编。**

### 具体做法

- 别人给你盘:**先别问是谁**,判断写完再问
- 名人命例:**先遮住名字**(《滴天髓》案例可以只抄八字)
- 自己身边人:让对方**只报生辰**,别说近况

---

## 怎么用

```
1. 复制 模板.md → 改名 YYYY-MM-DD-代号.md
2. 填【第一步:盘面】(客观信息,不含任何结论)
3. 填【第二步:判断】—— 写完之前不许看答案
4. 揭晓,填【第三步:实际】
5. 填【第四步:复盘】—— 差在哪,为什么差
6. 隔一个月回看,填【一个月后再看】
```

### 频率建议

**一周 3 到 5 个。** 少了没量,多了写不动。

坚持三个月 ≈ 50 个盘,足够跑出第一批模式。

## 命例从哪来

按可反馈性排序:

| 来源 | 反馈质量 | 说明 |
|---|---|---|
| **《滴天髓阐微》案例** | **最好** | 任铁樵每条配实例并给出判断,可以直接对答案 |
| **自己** | 好 | 结局你最清楚,但**最容易事后归因**,要格外小心 |
| **家人、密友** | **最好** | 知道细节,又不是自己,偏见小 |
| 名人 | 中 | 资料多但生辰常有误;且太容易先入为主 |
| 陌生人 | 差 | 无法验证 |

**推荐主力:《滴天髓阐微》的案例 + 身边熟人。**

## 复盘的四类错误

差了之后,归到这四类里。**归类比"我错了"有用得多。**

| 类型 | 意思 | 怎么改 |
|---|---|---|
| **A. 排盘错** | 节气、真太阳时、子时搞错 | 机械错误,查[第 7 章](../00-组合之书/第2部-排盘/07-四柱排法.md) |
| **B. 强弱判错** | 旺衰强弱四字混了、根数错了 | 回[第 11](../00-组合之书/第3部-强弱/11-旺衰强弱四字之辨.md)、[12 章](../00-组合之书/第3部-强弱/12-通根与虚透.md) |
| **C. 取用神错** | 优先级用反、格局定错 | 回[第 24 章](../00-组合之书/第5部-用神/24-五法冲突时的优先级.md) |
| **D. 量的判断错** | 方向对,但轻重估反了 | **这类最难改,只能靠量** |

**D 类占比会随着练习上升——那是好事,说明 A/B/C 已经不犯了。**

## 记分

每个盘按三档自评,不要细分:

| 档 | 标准 |
|---|---|
| **✓ 中** | 主要判断对(格局 + 用神 + 大方向) |
| **△ 半** | 方向对,程度或细节偏 |
| **✗ 错** | 主要判断反了 |

**别算准确率。** 算准确率会诱使你去挑好判的盘。

要看的是**趋势**:三个月前的错误类型 vs 现在的错误类型。**从 A/B/C 转到 D,就是在进步。**

---

## 一个月后再看

**这一栏最重要,也最容易跳过。**

刚复盘时你的解释总是很顺(因为刚知道答案)。隔一个月再看,你会发现:

- 有些「我当时就该看出来」的,现在还是看不出来 → **说明那不是疏忽,是真不会**
- 有些当时觉得难的,现在一眼就懂 → **说明真的在长**

**日历提醒设一个月。**
