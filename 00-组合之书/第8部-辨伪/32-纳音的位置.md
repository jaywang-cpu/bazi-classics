# 第 32 章 · 纳音的位置

> [← 上一章](./31-神煞该信多少.md)　·　[目录](../README.md)　·　[下一章 →](./33-各书冲突总表.md)

## 这章讲什么

**纳音不是假的,但它和子平法不兼容。** 这一章说清它是什么、为什么不能混用、以及它真正的位置在哪。

---

## 一、纳音是什么

**六十甲子每两组配一个「五行 + 物象」。**

| 干支 | 纳音 |
|---|---|
| 甲子 乙丑 | 海中金 |
| 丙寅 丁卯 | 炉中火 |
| 戊辰 己巳 | 大林木 |
| 庚午 辛未 | 路旁土 |
| 壬申 癸酉 | 剑锋金 |
| 甲戌 乙亥 | 山头火 |
| 丙子 丁丑 | 涧下水 |
| 戊寅 己卯 | 城头土 |
| 庚辰 辛巳 | 白蜡金 |
| 壬午 癸未 | 杨柳木 |
| …… | (共 30 组) |

---

## 二、为什么不能和子平法混用

### 核心问题:同一组干支,两个五行

| 干支 | 本气五行 | 纳音五行 |
|---|---|---|
| **戊辰** | 天干戊土 + 地支辰土 = **土** | **大林木** |
| **庚午** | 天干庚金 + 地支午火 | **路旁土** |
| **壬申** | 天干壬水 + 地支申金 | **剑锋金** |

**戊辰到底是土还是木?**

- 用子平法推:它是土,克水、生金、被木克
- 用纳音推:它是木,克土、生火、被金克

**两套推理会得出完全相反的结论。同时用,系统就自相矛盾。**

---

## 三、真诠的态度

### 原文 · 子平真诠

> 而俗书谬论，以甲为大林，盛而宜斩，乙为微苗，脆而莫伤,**可为不知阴阳之理者矣**。

### 徐乐吾补充

> 大林微苗之喻，本为纳音取譬之词,**俗书传讹,而无知之人妄执之耳**。
>
> 学命者先明干支阴阳之理，察其旺衰进退之方，**庶不致为流俗所误也**。

### 白话

烂书说甲是「大林木」应该砍、乙是「微苗」不能伤,**这是完全不懂阴阳之理**。

大林、微苗本来是**纳音**的比喻,烂书传错了,无知的人还当真理死抱着。

学命的人先把干支阴阳的道理弄明白、看清旺衰进退的方向,**才不会被流俗带偏**。

### 这段批评的精确性

**注意徐乐吾骂的是什么。**

他不是说「纳音是假的」,他说的是:**把纳音的物象比喻,拿来当天干性质用,是跨系统混用,是错的。**

例:「甲是大林木,盛而宜斩」——

- 「大林木」是**戊辰己巳**的纳音,和天干甲**毫无关系**
- 把它安到甲头上,再推出「甲需要庚金来砍」——**推理链条从第一步就是错的**

> **这是一个典型的概念误植:把 A 系统的标签贴到 B 系统的对象上。**

---

## 四、纳音为什么只能背不能推

### 子平法的五行是可推导的

```
甲为什么属木?
  因为它是木之阳(第 2 章)
乙为什么属木?
  因为它是木之阴
寅为什么属木?
  因为它是木在地上的形(第 3 章)
```

**每一条都能从「一气分阴阳、阴阳生五行」推出来。**

### 纳音的五行是约定的

```
甲子乙丑为什么是"海中金"?
  → 有几套说法(隔八相生、律吕、五行大义……),互不一致
  → 且都不能从干支本身的五行推出来
```

**只能背,不能推。**

### 后果

> **一个只能背不能推的规则,无法被检验对错。**

如果甲子是海中金是**约定的**,那把它约定成「海中木」也一样成立——**没有任何内在依据能否定它**。

**这样的规则不能进入推理系统。**

## 五、五本书的态度

| 书 | 用纳音吗 | 说明 |
|---|---|---|
| **子平真诠** | **明确排斥** | 「不知阴阳之理」 |
| **滴天髓** | **不用** | 全书不提 |
| **穷通宝鉴** | **不用** | 只讲干支本气的调候 |
| **三命通会** | **大量使用** | 汇编性质,收录 ≠ 认可 |
| **渊海子平** | **使用** | 早期形态,子平法尚未与纳音分离 |

### 一条历史线索

**子平法的成熟过程,就是和纳音分离的过程。**

```
唐 · 李虚中     年月日三柱,大量用纳音
宋 · 徐子平     加时柱,以日干为主 —— 开始转向干支本气
明 · 三命通会   汇编,两套并存
清 · 子平真诠   明确排斥纳音
清 · 滴天髓阐微 完全不用
```

**越成熟的著作,越不用纳音。** 这是一条清晰的趋势。

## 六、那纳音真正的位置在哪

**纳音不是垃圾,它是另一套完整的系统,有它自己的用武之地:**

| 领域 | 纳音的作用 |
|---|---|
| **择日** | 选吉日,纳音五行与事项五行相配 |
| **六壬** | 部分课体用纳音 |
| **堪舆(风水)** | 分金、坐山与纳音相配 |
| **合婚(传统)** | 男女纳音相生相克 |

**在这些领域里,纳音有它自成体系的用法。** 问题只出在把它掺进子平八字。

### 一个类比

> 公制和英制都是有效的度量系统。
> 但在同一个计算里,**一半用米一半用英尺,结果必然错**。
>
> 纳音和子平法的关系就是这样。

## 七、常见的混用错误

### 1. 拿纳音判断日主强弱

「他是海中金命,金在水里,所以身弱」——**错**。

日主强弱只看日干与四柱的五行关系(第 3 部),和纳音无关。

### 2. 拿纳音物象推性格

「大林木命的人高大挺拔」「炉中火的人性子急」——**错**。

性格看十神组合(第 4 章),不看纳音。

### 3. 拿纳音合婚

「他是路旁土,你是杨柳木,木克土,不合」——**错**(在子平法框架内)。

八字合婚(如果一定要做)看的是双方喜忌是否互补,不是纳音相克。

### 4. 「大林木盛而宜斩」这类

**真诠专门骂的就是这个**。见上文第三节。

---

## 八、一个诚实的说明

**本书对纳音的立场,不是「它没用」,而是「它不在这套系统里」。**

判断一个东西该不该进入某个推理系统,标准是:

```
1. 它能否从这个系统的基本假设推导出来?
2. 它是否参与这个系统的核心运算(五行生克)?
3. 用它得出的结论,是否与系统内其他结论一致?
```

**纳音三条全不满足。** 所以它不进入子平法。

> 这和第 31 章对神煞的处理是**同一个标准**。
>
> 本书第八部的方法论就是这一条:**不问「它是真是假」,只问「它在不在这个系统里」。**

## 本章要点

1. **纳音 = 六十甲子每两组配一个五行 + 物象**,是另一套系统
2. **核心问题:同一组干支有两个五行**,两套推理会得出相反结论
3. 真诠骂的是**跨系统混用**(把纳音物象当天干性质),不是说纳音本身假
4. **子平法的五行可推导,纳音的五行只能背** —— 不可推 = 不可检验
5. **越成熟的著作越不用纳音**:真诠排斥、滴天髓不用、穷通不用
6. 纳音真正的位置:**择日、六壬、堪舆、传统合婚**
7. 四种常见混用错误:判强弱、推性格、合婚、大林木那类比喻
8. **本书标准**:不问真假,只问**「它在不在这个系统里」**
