# 五书冲突对照表

五本古籍打架的地方,以及该信谁。

> 缩写:**真诠** = 子平真诠 · **滴天** = 滴天髓阐微 · **穷通** = 穷通宝鉴 · **三命** = 三命通会 · **渊海** = 渊海子平

---

## 一、神煞该信多少 —— 冲突最激烈

| 书 | 立场 |
|---|---|
| **三命** | 大量收录。天乙贵人、驿马、桃花、羊刃、空亡……几百种,占了全书极大篇幅 |
| **渊海** | 同样大量收录,是神煞体系的早期来源 |
| **真诠** | **正面否定**。专章《论星辰无关格局》,说神煞与格局无关 |
| **滴天** | 同样否定,认为看神煞是舍本逐末 |
| **穷通** | 基本不谈,只讲调候 |

### 真诠原文

> 八字格局，专以月令用神，配以四柱，至于星辰好歹，具由格局生出。……何用二者哉？
>
> 今人不知命理，妄以吉星凶煞论命，谓某人有某星故贵，某人有某煞故贱，不知贵贱在格局，星煞不过附会耳。

**白话**:八字的格局只看月令用神配四柱。至于什么吉星凶煞好不好,全是从格局里派生出来的——格局好,凶煞也不凶;格局坏,吉星也救不了。现在的人不懂命理,拿吉星凶煞论命,说某人有某星所以贵、有某煞所以贱,**不知道贵贱在格局,神煞只是附会**。

### 判断

**信真诠和滴天,不信三命。**

理由:神煞的绝大多数是**按固定公式从年支或日支推出来的**,不参与五行生克。同一个天乙贵人,可以出现在贵命也可以出现在贱命,没有区分度——一个不能区分的指标,就是没有信息量的指标。

三命通会收录神煞,是因为它的定位是**汇编**,不是**判断**。万民英在收,不等于他在信。

**例外**:有几个「神煞」其实是五行关系的别名,该保留——

| 名称 | 实质 |
|---|---|
| 羊刃 | 日干的帝旺之支,是真实的五行力量 |
| 禄 | 日干的临官之支,同上 |
| 桃花(咸池) | 子午卯酉,四正之支 |
| 驿马 | 寅申巳亥,四生之支 |

这几个之所以有用,是因为它们**本来就是十二长生和四正四生的另一种叫法**,不是外挂。

## 二、阴干的十二长生要不要逆行

| 书 | 立场 |
|---|---|
| **渊海 / 三命** | 阳顺阴逆。甲长生在亥,乙长生在午 |
| **真诠** | **采用**阳顺阴逆,专章论述 |
| **滴天** | **反对**。任铁樵明确说阴干不应逆行,乙木一样长生在亥 |

### 真诠原文

> 阳主聚，以进为进，故主顺；阴主散，以退为退，故主逆。长生沐浴等项，所以有阳顺阴逆之殊也。
>
> 即以甲乙论……乙木反是，午月枝叶繁盛，即为之生，亥月枝叶剥落，即为之死。以质而论，自与气殊也。

**白话**:阳气主聚合,往前走算前进,所以顺行;阴气主发散,往后退算前进,所以逆行。以甲乙为例,甲木亥月长生、午月死;乙木反过来,午月枝叶最茂就算它生,亥月枝叶掉光就算它死。**因为甲论的是气,乙论的是质,两者本来不同。**

### 滴天髓的反对

任铁樵认为:木就是木,甲乙只是同一股木气的阴阳两面,**不可能一个在亥最旺、一个在亥最死**。乙木在亥月照样得水生,说它死是违背五行常识的。

### 判断

**实务上跟滴天,理论上知道真诠为什么那么说。**

具体操作:
- 判断**日主强弱**时,按滴天,乙木在亥子照样有力
- 但真诠给了一个有价值的洞察:**甲论气、乙论质**。气看的是趋势,质看的是存量。这个区分在看「甲乙谁更能承受克伐」时有用

真诠自己也留了后门,他说:

> 阳长生有力，而阴长生不甚有力，然亦不弱。若是逢库，则阳为有根，而阴为无用。

**白话**:阳干的长生力量大,阴干的长生不太有力,但也不算弱。至于遇到墓库,阳干算有根,阴干就没用了。

——**"然亦不弱"四个字,等于他自己也不完全信阴逆那一套。**

## 三、墓库要不要冲开才能用

| 书 | 立场 |
|---|---|
| **三命 / 渊海** | 墓库如仓库,**必须刑冲才能打开**,里面的东西才能用 |
| **真诠** | **痛批**。专章《论墓库刑冲之说》 |
| **滴天** | 同样反对 |

### 真诠原文

> 时产谓投库而必冲者，俗书之谬也。
>
> 阳干之墓库，本气未绝，故为有根；……若必待刑冲而后能用，则四柱纯粹者，反不如刑冲破害之命矣，有是理乎？

**白话**:说什么入了墓库必须冲开才能用,**这是烂书的谬论**。阳干在墓库里本气还没断,所以算有根。要是非得刑冲之后才能用,那四柱干净的命反而不如被刑冲破害的命了——**天下有这个道理吗?**

### 判断

**信真诠。** 这是逻辑上的硬伤:如果冲库是好事,那所有八字都该盼着被冲,这与命理其他所有原则矛盾。

**实际用法**:辰戌丑未里藏的余气,天然就能当根用,轻重而已。冲不冲是另一回事(冲主动荡),和"能不能用"不是一个问题。

## 四、格局重要还是调候重要

| 书 | 立场 |
|---|---|
| **真诠** | 格局第一。用神专求月令,调候只在《论用神配气候得失》里带一笔 |
| **穷通** | 调候第一。全书就是一张调候表,不谈格局 |
| **滴天** | 中和第一,视情况而定 |

### 真诠原文

> 论命惟以月令用神为主，然亦须配气候而互参之。
>
> 譬如英雄豪杰，生得其时，自然事半功倍；生不得时，虽有奇才，无所用之。

**白话**:论命以月令用神为主,但也要参考气候。就像英雄豪杰,生逢其时自然事半功倍;生不逢时,再有本事也用不上。

### 判断

**不是二选一,是有先后。**

推荐的优先级(本书第 24 章详述):

1. **先看气候是否极端**。金水生在严冬、木火生在酷夏,寒燥已到极处 → **调候优先**,这时格局再漂亮也没用
2. **气候不极端** → **格局优先**,按真诠那套走
3. 格局定了之后,**用调候来分高低**——同样是正官格,一个调候到位一个不到位,层次差很远

穷通宝鉴之所以只讲调候不讲格局,是因为它本来就是**给已经会格局的人用的补充表**,不是入门书。单独拿它当教材才会走偏。

## 五、「得时为旺、失时为衰」对不对

| 书 | 立场 |
|---|---|
| **渊海 / 三命** | 得令即旺,失令即衰 |
| **真诠** | 是死法,要活看 |
| **滴天** | 彻底拆开:旺衰 ≠ 强弱 |

### 真诠原文

> 书云，得时俱为旺论，失时便作衰看，虽是至理，亦死法也。然亦可活看。
>
> 夫五行之气，流行四时，虽日干各有专令，而其实专令之中，亦有并存者在。……春土何尝不生万物，冬日何尝不照万国乎？

**白话**:书上说得令就算旺、失令就算衰,虽然是正理,**但这是死规矩**,要活看。五行之气在四季流行,虽然各有当令的时候,但当令之中其他几行也并没有消失。春天的土照样长万物,冬天的太阳照样照天下。

### 徐乐吾的补充(这是全书最有价值的一条)

> 旺衰强弱四字，昔人论命，每笼统互用，不知须分别看也。
>
> **大致得时为旺,失时为衰;党众为强,助寡为弱。** 故有虽旺而弱者,亦有虽衰而强者。

**白话**:旺、衰、强、弱这四个字,古人论命常常混着用,不知道要分开看。

- **旺衰看时令**:生在当令的月份就旺,不当令就衰
- **强弱看党众**:比劫印绶多、通根多就强,孤立无援就弱

所以有**虽旺而弱**的(当令但四柱无援),也有**虽衰而强**的(不当令但满盘帮手)。

### 判断

**这是全五本书里最重要的一条区分,信滴天+徐注。**

例:
- 甲木生寅月 = **得时旺**,但天干庚辛、地支酉丑一片金 → **党寡而弱**。虽秉令而不强
- 甲木生申月 = **失时衰**,但比劫印绶重叠、年日时支通根 → **党众而强**。虽失时而不弱

本书第 11 章专讲这个。

## 六、从格什么时候成立

| 书 | 立场 |
|---|---|
| **真诠** | 归在《论杂格》,着墨不多 |
| **滴天** | 专论从象、假从,条件严格 |
| **三命** | 收了大量从格名目,标准宽松 |

### 滴天髓的标准(徐乐吾整理)

> 五阳从气不从势，五阴从势无情义。

**白话**:
- **阳干**:只要四柱稍有根,或者印星有根,**就不从**。弱就弱着
- **阴干**:财官一旺就跟着走,哪怕自己通了月令。但**印绶有根就不从**

### 判断

**信滴天。** 三命通会的从格标准太松,会把大量普通命误判成从格,方向一错满盘皆错。

实操口诀:**先找根,后论从**。日主但凡有一个像样的根(长生、禄、旺、或强力的印),就不要考虑从格。

## 七、纳音要不要用

| 书 | 立场 |
|---|---|
| **三命 / 渊海** | 大量使用。海中金、炉中火、大林木…… |
| **真诠** | **明确排斥** |
| **滴天** | 不用 |

### 真诠原文

> 而俗书谬论，以甲为大林，盛而宜斩，乙为微苗，脆而莫伤，可为不知阴阳之理者矣。

**白话**:烂书说甲是"大林木"该砍、乙是"微苗"不能伤,**这是完全不懂阴阳之理**。

### 徐乐吾补充

> 大林微苗之喻,本为纳音取譬之词,俗书传讹,而无知之人妄执之耳。

**白话**:大林、微苗这类比喻本来是**纳音**的说法,烂书传错了,无知的人还当真理抱着不放。

### 判断

**不用。**

纳音是另一套独立系统(六十甲子配五行,与本气五行无关),它和子平法的生克体系不兼容。混用会得出矛盾结论。

想研究纳音,当作一门单独的术看,别掺进八字。

## 八、快速对照速查

| 争议点 | 该信谁 | 一句话 |
|---|---|---|
| 神煞 | 真诠 / 滴天 | 不用。除了禄、刃、四正四生这几个五行别名 |
| 阴干逆行 | 滴天 | 实务不逆行,但记住"甲论气乙论质"这个洞察 |
| 冲库才能用 | 真诠 | 不用冲,墓库本来就能当根 |
| 格局 vs 调候 | 分先后 | 气候极端时调候优先,否则格局优先 |
| 得时即旺 | 滴天 + 徐注 | 旺衰看时令,强弱看党众,四字分开 |
| 从格 | 滴天 | 先找根后论从,有根就不从 |
| 纳音 | 真诠 | 不用,是另一套系统 |
