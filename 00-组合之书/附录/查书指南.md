## 按问题类型查

| 我想知道 | 查哪本 | 具体位置 |
|---|---|---|
| **怎么排盘、起大运** | 渊海子平、三命通会 | 起例、歌诀部分 |
| **某个地支藏哪几个天干** | 三命通会 | 《十二支分配地理》 |
| **某个格局怎么成、怎么破** | **子平真诠** | 对应格局章 |
| **格局成了之后走什么运** | **子平真诠** | 「论 X 取运」各章 |
| **这个日主生在这个月该用什么** | **穷通宝鉴** | 按「论 X 木/火/土/金/水」+ 季节查 |
| **日主强弱怎么判** | **滴天髓阐微** | 《衰旺》《中和》 |
| **十天干各自什么性情** | **滴天髓阐微** | 《天干》 |
| **从格、化格成不成立** | **滴天髓阐微** | 《从象》《化象》《假从》《假化》 |
| **寒暖燥湿怎么调** | 滴天髓(原理)+ 穷通宝鉴(答案) | 《寒暖》《燥湿》 |
| **某个神煞怎么算** | 三命通会 | 神煞各篇(**只查算法,不用来判断**) |
| **看实战案例** | **滴天髓阐微** | 全书,每条都配命例 |
| **六亲怎么看** | 滴天髓阐微 | 《夫妻》《子女》《父母》《兄弟》 |

## 按书的定位

### 子平真诠 —— 主教材

**读,不查。** 从头到尾读完,建立框架。

**独有内容**(其余四本都没有):
- 相神
- 成败救应
- 成格变格
- 「论星辰无关格局」(反神煞的正面论述)

### 滴天髓阐微 —— 第二本 + 案例库

**先读后查。**

**独有价值**:
- 旺衰强弱讲得最深
- 十干性情描述最生动
- **案例最多**,是唯一能当实战教材的

### 穷通宝鉴 —— 工具书

**只查,不读。**

用法:确定日主 + 出生月 → 直接翻到对应条目 → 看它说该用什么、走什么运。

**查法示例**:甲木生子月 → 翻到「论木」→「三冬甲木」→ 找子月条目。

### 三命通会 —— 词典

**只查,绝不当教材。**

可以查:
- 藏干表
- 神煞算法
- 术语定义
- 各种起例

**不要用它下判断。**

### 渊海子平 —— 溯源

**了解这套术怎么长出来的。** 也可查排盘起例。

**注意**:书中的纳音、神煞、阳顺阴逆等说法,大半被后世推翻。

## 三种常见场景的完整流程

### 场景一:我要看一个八字

```
1. 排盘 → 本书第 7 章
2. 判强弱 → 本书第 10-12 章;深挖去《滴天髓·衰旺》
3. 定格局 → 本书第 14-18 章;细节回《子平真诠》对应格局章
4. 取用神 → 本书第 24 章优先级
   若涉及调候 → 查《穷通宝鉴》对应条目
5. 看行运 → 本书第 26 章;细节回《子平真诠》「论 X 取运」
```

### 场景二:我看到一个说法,不知真假

```
1. 用本书第 33 章的"辨伪五问"过一遍
2. 查这个说法在不在《子平真诠》《滴天髓》《穷通宝鉴》里
   三本都没有 → 大概率不用
3. 若涉及本书列出的十大冲突 → 直接查第 33 章总表
```

### 场景三:我想查某个术语

```
本书[术语索引](./索引.md) → 找到章节
不够详细 → 《三命通会》查定义
要看它在实战里怎么用 → 《滴天髓阐微》找案例
```

## 一条建议

**不要五本平行读。**

正确顺序:

```
第 1 遍  只读本书(组合之书)—— 建框架
第 2 遍  读《子平真诠》原文 —— 补细节,验证框架
第 3 遍  读《滴天髓阐微》案例 —— 把框架填实
之后     穷通、三命当工具书用一辈子
渊海     有兴趣时翻,溯源
```

**《三命通会》60 万字,从头读到尾是最常见的浪费时间的方式。** 它是词典,没人从头读词典。
