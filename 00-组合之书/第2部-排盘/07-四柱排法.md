# 第 7 章 · 四柱排法

> [目录](../README.md)　·　[下一章 →](./08-大运排法.md)

## 这章讲什么

**把出生时间换成八个字。** 这一步是纯机械的,但有四个坑,踩了后面全错。

---

## 一、四柱是什么

| 柱 | 干支来自 | 代表 |
|---|---|---|
| **年柱** | 出生年 | 祖上、少年(1-16) |
| **月柱** | 出生月 | 父母兄弟、青年(17-32)、**格局所在** |
| **日柱** | 出生日 | 自己(天干)与配偶(地支)、中年(33-48) |
| **时柱** | 出生时辰 | 子女、晚年(49-) |

八个字 = 四个天干 + 四个地支。

> **月柱最重要**。第 14 章会讲透:格局只从月令取。

---

## 二、坑一:年柱以立春为界

**不是正月初一,是立春。**

| 出生时间 | 年柱 |
|---|---|
| 2026 年 1 月 20 日(立春前) | 算 **乙巳**年,不是丙午 |
| 2026 年 2 月 10 日(立春后) | 算 **丙午**年 |

**为什么**:第 3 章说过,地支是「时令的次序」。八字用的是**节气历**,不是农历也不是公历。立春是寅月的开始,也是新的一年的开始。

> 农历新年(正月初一)是民俗,和命理的年界无关。这一条每年都有人错。

---

## 三、坑二:月柱以「节」为界

一年二十四个节气,分十二个**节**、十二个**气**。**月份的分界是「节」,不是「气」。**

| 月支 | 从这个节开始 | 大约日期 |
|---|---|---|
| 寅(正月) | **立春** | 2/4 |
| 卯(二月) | **惊蛰** | 3/6 |
| 辰(三月) | **清明** | 4/5 |
| 巳(四月) | **立夏** | 5/6 |
| 午(五月) | **芒种** | 6/6 |
| 未(六月) | **小暑** | 7/7 |
| 申(七月) | **立秋** | 8/8 |
| 酉(八月) | **白露** | 9/8 |
| 戌(九月) | **寒露** | 10/8 |
| 亥(十月) | **立冬** | 11/7 |
| 子(十一月) | **大雪** | 12/7 |
| 丑(十二月) | **小寒** | 1/6 |

**中间的雨水、春分、谷雨等叫「气」,不管月份分界。**

> 生在节交接的当天,**必须查准确的交节时刻**(精确到分)。差几分钟月柱就变了,格局全变。

### 月柱天干:五虎遁

地支定了,天干按**年干**推:

| 年干 | 正月(寅月)的天干 |
|---|---|
| 甲、己 | **丙**寅 |
| 乙、庚 | **戊**寅 |
| 丙、辛 | **庚**寅 |
| 丁、壬 | **壬**寅 |
| 戊、癸 | **甲**寅 |

口诀:**甲己之年丙作首,乙庚之岁戊为头,丙辛必定寻庚起,丁壬壬位顺行流,若言戊癸何方发,甲寅之上好追求。**

定了正月,后面顺排:丙寅 → 丁卯 → 戊辰 → ……

### 原文印证 · 子平真诠(徐乐吾注)

> 天干动而不居者，如甲己之年，以丙寅为正月；乙庚之岁，以戊寅为正月也。地支止而不迁者，正月必为寅，二月必为卯也。

**白话**:所谓"天干会动",就是甲年己年的正月是丙寅、乙年庚年的正月是戊寅——天干在换。所谓"地支不动",就是正月永远是寅、二月永远是卯。

> 这正是第 2 章那句话的实际用法。

---

## 四、坑三:日柱只能查

**日柱没有公式,只能查万年历。**

甲子日起于某个历史起点,连续不断循环至今,中间不受年月影响。

> 现在用排盘软件即可。但要确认软件的**节气数据准确**,以及是否处理了下面的时区问题。

---

## 五、坑四:时柱,以及子时的麻烦

### 时辰划分

| 时辰 | 时间 |
|---|---|
| 子 | 23:00 - 01:00 |
| 丑 | 01:00 - 03:00 |
| 寅 | 03:00 - 05:00 |
| 卯 | 05:00 - 07:00 |
| 辰 | 07:00 - 09:00 |
| 巳 | 09:00 - 11:00 |
| 午 | 11:00 - 13:00 |
| 未 | 13:00 - 15:00 |
| 申 | 15:00 - 17:00 |
| 酉 | 17:00 - 19:00 |
| 戌 | 19:00 - 21:00 |
| 亥 | 21:00 - 23:00 |

### 时柱天干:五鼠遁

按**日干**推:

| 日干 | 子时的天干 |
|---|---|
| 甲、己 | **甲**子 |
| 乙、庚 | **丙**子 |
| 丙、辛 | **戊**子 |
| 丁、壬 | **庚**子 |
| 戊、癸 | **壬**子 |

口诀:**甲己还加甲,乙庚丙作初,丙辛从戊起,丁壬庚子居,戊癸何方发,壬子是真途。**

### 子时的争议

**23:00-24:00 这一个小时,算今天的子时还是明天的子时?**

| 说法 | 主张 |
|---|---|
| **早子时/晚子时** | 23:00 后**日柱换新**,时柱用子。即 23:30 出生 = 明日日柱 + 子时 |
| **夜子时** | 23:00-24:00 **日柱不换**,仍是今天,时柱用子 |

**本书立场:用第一种(23:00 换日)。**

理由:地支的分界是**气的分界**,不是钟表的分界。子时是一天中阴极转阳的点,新的一天从阴阳转折处开始,而不是从午夜零点开始。零点是现代计时约定,古人没有这个概念。

> 但要知道有争议。生在 23:00-24:00 的,两种日柱都排一遍对照命主实际经历。

### 真太阳时

**北京时间不是当地时间。**

中国全境用东八区(东经 120°)标准时,但实际太阳位置按经度差:

> **每偏离 1 个经度 = 4 分钟**

例:乌鲁木齐(东经 87°)比东经 120° 偏西 33 度 → 时差约 **132 分钟**。北京时间中午 12 点,当地真太阳时约 9:48,是**巳时不是午时**。

**修正公式:**

```
真太阳时 = 北京时间 + (当地经度 - 120) × 4 分钟 + 均时差
```

> 均时差是地球轨道椭圆造成的偏差,全年在 ±16 分钟之间,精确排盘要查表。一般排盘软件都内置了。

**什么时候必须修正:**
- 出生地在西部(新疆、西藏、川西等)
- 出生时间在时辰交界的半小时内

---

## 六、完整流程

```
1. 确认出生地经度 → 修正真太阳时
2. 查交节时刻 → 定年柱、月支
3. 五虎遁 → 定月干
4. 查万年历 → 定日柱
5. 定时支(注意子时)→ 五鼠遁定时干
6. 标出日主,其余七字定十神
7. 标出各柱地支藏干
```

### 排完之后要做的三件事

1. **圈出日主** —— 一切以它为原点
2. **圈出月令** —— 格局在这里
3. **标出每个地支的藏干** —— 第 12 章判断通根要用

---

---

## 本章要点

1. **年柱以立春为界**,不是正月初一
2. **月柱以「节」为界**,不是「气」,不是农历初一
3. 月干用**五虎遁**(甲己丙作首),时干用**五鼠遁**(甲己还加甲)
4. **日柱只能查万年历**,无公式
5. 子时争议:本书用 **23:00 换日**,但知道有另一说
6. **真太阳时**必须修正,西部地区差可达两小时
7. 排完立刻做三件事:**圈日主、圈月令、标藏干**
