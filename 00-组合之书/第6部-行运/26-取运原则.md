# 第 26 章 · 取运原则

> [← 上一章](./25-运的本质.md)　·　[目录](../README.md)　·　[下一章 →](./27-成格变格.md)

## 这章讲什么

**按格局取运。** 《子平真诠》给八个格各配了一章「取运」,这一章把它们汇总成表。

---

## 一、总原则

### 原文 · 子平真诠

> 何谓喜忌？如喜印绶而运逢官煞，喜财而运逢食伤之类是也。
>
> 何谓忌？如喜印绶而运逢财，喜财而运逢比劫之类是也。

### 白话

**什么叫喜**:喜欢印绶,结果走到官杀运(官杀生印);喜欢财,结果走到食伤运(食伤生财)。

**什么叫忌**:喜欢印绶,结果走到财运(财克印);喜欢财,结果走到比劫运(比劫夺财)。

### 提炼

```
喜 = 生用神、护用神、生相神
忌 = 克用神、克相神、生忌神
```

**注意:运不是直接给你用神,而是「生用神的东西」也算喜。** 这一层容易漏。

## 二、八格取运总表

按《子平真诠》八格取运各章汇总。

### 正官格

| | 运 |
|---|---|
| **喜** | 财运(生官)、印运(护官,尤其原局有伤官时)、身弱时的比劫印运 |
| **忌** | **伤官运**(克官)、**七杀运**(混杂)、冲月令的运 |
| 分情况 | 原局财多身弱 → 喜印比;原局印重 → 喜财 |

> 原则:**看原局缺什么补什么。官格已成,运只要不破坏它。**

### 财格

| | 运 |
|---|---|
| **喜** | 食伤运(生财)、官运(护财)、身弱时的印比运 |
| **忌** | **比劫运**(夺财)、身弱时的财官运(担不起) |
| 分情况 | 财旺身弱 → **先喜印比**;财轻身旺 → 喜食伤财 |

### 印格

| | 运 |
|---|---|
| **喜** | 官杀运(生印)、比劫运(护印) |
| **忌** | **财运**(破印) |
| 分情况 | 印重身旺 → **反喜财运、食伤运**(泄秀、破壅塞) |

> 注意这里的反转:**印格忌财是通例,印重身旺时财反成救星。**

### 食神格

| | 运 |
|---|---|
| **喜** | 财运(食生财)、身旺时的食伤财运 |
| **忌** | **枭印运**(夺食)、身弱时的财官运 |
| 分情况 | 食神制杀者 → **忌财运**(财生杀泄食,两头坏) |

### 七杀格

| | 运 |
|---|---|
| **喜** | 食伤运(制杀)、印运(化杀)、身旺运(任杀) |
| **忌** | **财运**(生杀)、制杀太过时的食伤运 |
| 分情况 | 杀重身轻 → 喜印比;身强杀浅 → 喜财生杀 |

> **「身强杀浅喜财」**是七杀格的一个反转:杀太弱了反而要养一养,才有「权」。

### 伤官格

| | 运 |
|---|---|
| **喜** | **看用什么**:用财者喜财运;佩印者喜印运、官杀运 |
| **忌** | 用财者忌比劫印;佩印者忌财运(破印) |
| 见官 | **有印或有财则不忌**,否则大忌 |

> 伤官格取运最复杂,因为它有四种配法(第 16 章),**每种配法的喜忌完全不同**。

### 阳刃格

| | 运 |
|---|---|
| **喜** | **官杀运**(制刃)、食伤运(泄) |
| **忌** | **比劫运**(刃上加刃)、印运(更旺) |
| 特别 | **官杀运是阳刃格的黄金期** |

### 建禄月劫格

| | 运 |
|---|---|
| **喜** | 财官运、食伤运(有东西可用) |
| **忌** | 比劫运(更旺无处使) |
| 分情况 | 用官者喜财运护;用财者喜食伤运通 |

## 三、一条贯穿的原则:补不足,不加有余

八格取运表看着复杂,底下只有一句话:

> **原局缺什么,运补什么;原局多什么,运别再加。**

### 例:同样是官格

| 原局 | 缺什么 | 喜什么运 |
|---|---|---|
| 官星有力,但身弱 | 身 | **印、比劫** |
| 官星虚透无根 | 官 | **财**(生官) |
| 官星被伤官克 | 制伤之物 | **印** |
| 身官两旺,配合完美 | 不缺 | **平安运即可**,不必大补 |

**四个都是官格,喜的运完全不同。**

> 这就是为什么不能背「某格喜某运」——**要看这个具体命局缺什么。**

---

## 四、最凶的三种运

按第 17 章「伤相甚于伤用,伤用甚于伤身」排序:

### 1. 冲克相神的运(最凶)

相神一倒,**格局结构崩塌**。

例:七杀格用食神制杀,走到枭印运 → **食神被夺,杀失去控制,直接攻身。**

### 2. 冲克用神的运

用神被伤,**格局降级**,但结构还在。

### 3. 冲月令的运

月令是格局所在。冲月令 = **动格局的根基**。

> 真诠反复强调官格「切忌刑冲破害」,指的主要就是冲月令。

### 一个补充:岁运并临

流年干支 = 大运干支时,**力量叠加**。

- 是喜神 → 大发
- 是忌神 → **大凶**

## 五、行运的三个阶段特征

### 起运前(0 到起运岁数)

**看流年配命局**(第 9 章,本书不用小运)。

这段时间主要受父母影响,看年月柱。

### 中年(约 25-55)

**大运的作用最明显。** 这段是格局能否兑现的关键期。

> 命好而中年运不济,往往就是徐乐吾说的「奇葩异卉不值花时」。

### 晚年

**运的影响减弱,命局本身的底子显现。**

传统说法:晚年看时柱和日支。

---

## 六、一个常见误区

### 「走到用神运就一定好」——不一定

三种例外:

**1. 用神运但被合被冲**

运的天干是用神,但被命局某个字合走 → **用神来了却用不上**。

**2. 用神太过**

原局用神已经够了,运再来一大堆 → **过犹不及**。

例:身弱用印,原局印已经有两个,再走印运 → **印重身旺,壅塞**。

**3. 用神运引发别的问题**

例:财格身弱,走印运帮身。印帮了身,但印克食伤 → **断了财源**。

> 所以取运也要用第 24 章的思路:**放回全局通盘看,不是孤立地判断「是不是用神」。**

## 五书对照

| 书 | 立场 |
|---|---|
| **子平真诠** | **八格各配一章取运**,共八章,最系统。本章汇总自它 |
| **穷通宝鉴** | 每个日主 + 月令条目后附行运建议,**最便于速查** |
| **滴天髓** | 案例演示,**最见功夫但不成表** |
| **三命通会** | 行运细则多而杂 |
| **渊海子平** | 早期表述 |

### 穷通宝鉴的行运建议

穷通的做法是:**给出调候用神之后,直接说该走什么运。**

例(甲木生子月):「用丙火解冻……**运喜南方**」。

> **这是最省事的查法**,但只处理调候维度。格局层面的取运还是要回真诠。

---

## 本章要点

1. **喜 = 生用神/护用神/生相神;忌 = 克用神/克相神/生忌神**
2. **运不必直接是用神**,「生用神的东西」也算喜
3. 八格取运表底下只有一句:**原局缺什么补什么,多什么别再加**
4. 同一个格,原局配置不同,**喜的运完全不同**。不能背固定答案
5. 最凶三种运:**冲克相神 > 冲克用神 > 冲月令**
6. **岁运并临**力量叠加,吉凶都放大
7. 三个例外:**用神被合冲、用神太过、用神引发新问题**
8. 取运也要**放回全局通盘看**,不是孤立判断
