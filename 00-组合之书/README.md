# 组合之书 · 子平命理通编

把五本核心古籍**打散重排**成一本按学习顺序推进的书。

---

## 为什么要有这本书

五本古籍各有各的毛病:

| 书 | 强在哪 | 缺什么 |
|---|---|---|
| 子平真诠 | 格局体系最清楚,像教材 | 几乎不讲调候,强弱判断说得少 |
| 滴天髓阐微 | 旺衰权衡最深,案例最活 | 原文是偈语,不成体系,新手抓不住 |
| 穷通宝鉴 | 调候用神一查就有 | 纯查表,不讲道理,只说结论 |
| 三命通会 | 最全,什么都收 | 60 万字大杂烩,神煞泛滥,自相矛盾 |
| 渊海子平 | 源头,能看清这套术怎么长出来 | 早期形态,很多说法后来被推翻 |

**更麻烦的是它们互相打架。** 同一个问题,《子平真诠》说 A,《三命通会》说 B,《滴天髓》说两个都不对。初学者读完五本,脑子里是五套互斥的规矩。

这本书干三件事:

1. **重排顺序** —— 按「符号 → 排盘 → 强弱 → 格局 → 用神 → 行运 → 应用」推进,每一步只依赖前一步
2. **标明出处** —— 每个论点注明来自哪本书,原文照录,后附白话
3. **正面处理冲突** —— 五书打架的地方单列,说清谁对谁错、为什么,以及该信哪个

读完这一本,五本古籍的精华都在;要查细节再回原书。

## 怎么用这本书

**第一遍**:第一部到第四部顺读,不跳。这四部是有依赖关系的,跳了后面看不懂。

**第二遍**:第五部到第七部,配合自己的八字看。

**平时**:第八部和附录当工具用。遇到某个说法拿不准,先查[冲突对照表](./附录/五书冲突对照.md)。

**每章格式**:

```
这章讲什么      ← 一句话
原文            ← 引用,标明出自哪本书
白话            ← 逐段翻译
五书对照        ← 这个问题各书怎么说,冲突在哪
本章要点        ← 可复述的几条
```
