# 第 22 章 · 专旺

> [← 上一章](./21-病药.md)　·　[目录](../README.md)　·　[下一章 →](./23-通关.md)

## 这章讲什么

**气势偏于一方,不可逆,只能顺。** 这是「中和」原则的例外,也是最容易和从格搞混的一块。

---

## 一、原文

### 子平真诠(徐乐吾注)

> **专旺**。四柱之气势，偏于一方其势不可逆，惟有**顺其气势**为用，或从或化，及一方专旺等格局皆是也。

### 白话

四柱的气势偏在一方,**这个势头不能逆着来**,只能顺着它的气势用。

包括:从格、化格、以及一方专旺的各种格局。

---

## 二、专旺 vs 从格:方向相反

这两个最容易混,先分清楚。

| | 专旺 | 从格 |
|---|---|---|
| 日主 | **极强** | **极弱** |
| 满盘是什么 | **比劫、印**(和我一伙的) | **财、官杀、食伤**(不是我的) |
| 为什么顺 | 强到没人能克 | 弱到无法抵抗 |
| 顺的对象 | **顺我自己** | **顺当权者** |

**共同点只有一个:都不能用中和的办法处理。**

### 关键区别

- **专旺**:我就是那个势,所以顺我 = 顺势
- **从格**:我不是那个势,顺势 = 放弃我

> 第 13 章讲从格,本章讲专旺。**判断时先看日主是极强还是极弱,方向就定了。**

---

## 三、五种专旺格

| 格 | 日主 | 满盘 | 别名 |
|---|---|---|---|
| **曲直格** | 甲乙 | 木(寅卯辰 / 亥卯未) | 仁寿格 |
| **炎上格** | 丙丁 | 火(巳午未 / 寅午戌) | |
| **稼穑格** | 戊己 | 土(辰戌丑未) | |
| **从革格** | 庚辛 | 金(申酉戌 / 巳酉丑) | |
| **润下格** | 壬癸 | 水(亥子丑 / 申子辰) | |

### 成立条件

```
1. 日主得月令(生在当令之月)
2. 地支会成方局或三合局(全或缺一)
3. 天干透出同类或印
4. 全局无克我之神(或克我者极弱且被制)
```

**第 4 条最关键。** 有一个有力的官杀在,专旺就不成立——因为「势」被打破了。

---

## 四、专旺格的喜忌

**一旦成格,喜忌和普通命局完全不同:**

| | 喜 | 忌 |
|---|---|---|
| 专旺格 | **比劫**(同我)、**印**(生我)、**食伤**(顺泄) | **官杀**(逆克)、**财**(引来官杀) |

### 为什么忌官杀

普通身旺命喜官杀克制。**专旺格反而最忌。**

原因:专旺的「势」已经形成一个整体。**用一点官杀去克它,克不动,反而激怒它。**

> 比喻:一条大江奔流,你拿块石头去挡,挡不住,只会激起更大的浪。
> 要么让它走,要么筑起真正的堤坝——但堤坝(强大的官杀)一旦存在,专旺格本身就不成立了。

### 为什么喜食伤

**食伤是「顺泄」**——把过盛的力量引导出去,变成才华、产出。

这是专旺格最好的出路:**不压制,而是给它一个出口。**

> 曲直格(木专旺)最喜见丙火:木生火,秀气吐出。这也是调候的需要。

---

## 五、化格

**化格**是专旺的另一种形式:日主与另一个天干**合化**,整个命局跟着化神走。

### 成立条件(严格)

```
1. 日主与月干或时干天合(甲己、乙庚、丙辛、丁壬、戊癸)
2. 化神当令(合化的那个五行,正好是月令)
3. 化神在盘中有力,成势
4. 无克化神之物
```

例:甲日主 + 己土在月干,生在辰戌丑未月,盘中土重 → **化土格**。

**成格后,这个命按土论,不按木论。**

### 真假化

| | 条件 | 处理 |
|---|---|---|
| **真化** | 全部条件满足 | 按化神论,喜生助化神 |
| **假化** | 条件不足(如化神不当令,或有克化神之物) | **按原来的日主论**,不化 |

> **化格标准比从格还严。** 大多数看似天合的八字,实际上都不化——因为「化神当令」这一条就卡掉了绝大多数。

---

## 六、判断流程

```
第 1 步  日主极强还是极弱?
        极强 → 可能是专旺,进第 2 步
        极弱 → 转第 13 章从格

第 2 步  满盘是不是一片同类?
        地支成方成局 + 天干透同类/印  → 继续
        混杂           → 不是专旺,按普通命局处理

第 3 步  有没有有力的官杀?
        有            → 不成专旺,按普通身旺处理
        无 / 极弱被制  → 专旺成立

第 4 步  确认是哪一格(曲直/炎上/稼穑/从革/润下)

第 5 步  定喜忌
        喜:比劫、印、食伤
        忌:官杀、财
```

### 另一条支线:化格

```
日主与邻干天合?
  是 → 化神当令吗?
        当令且成势且无克 → 真化,按化神论
        否               → 假化,按原日主论
  否 → 不考虑化格
```

---

## 七、和「中和」的关系

### 原文 · 滴天髓 · 中和

> 既识中和之正理，而于五行之妙，有全能焉。

### 任铁樵的关键解释(白话)

中和不是**「把所有东西压到中间」**,是**「各得其宜」**。

对一个专旺的命局来说:

> **顺着它的气势,就是它的中和。**

硬要压制它、把它拉回「不偏不倚」,**反而是破坏中和**。

### 这一层的意义

它解决了一个表面矛盾:

- 命理的总原则是「中和」
- 但专旺格恰恰是「极不中和」的,还偏偏是贵格

**答案:中和的对象不是「五行的数量」,是「气的运转」。**

- 一个五行均匀但互相打架的命局 → 数量中和,气不通,**不是中和**
- 一个一片木的专旺格,气畅通无阻 → 数量极偏,气通,**是中和**

> 这是全书对「中和」最重要的一次澄清。

---

## 八、专旺格的现实特征

传统上认为:

| 特征 | 说明 |
|---|---|
| 成就往往极高 | 力量集中,不分散 |
| 也极不稳定 | 一旦行运破格,跌得极惨 |
| 性格极端 | 一往无前,不肯回头 |
| 怕「破格运」 | 走到官杀运是大关口 |

**最怕的是「破格」**:走到官杀运,势被冲击。

> 因为专旺格没有「后备方案」——它的全部力量押在一个方向上。

### 本书立场:标准从严

和第 13 章从格同理:

> **误判代价不对称。** 把普通命误判成专旺 → 喜忌全反,大凶。

**实操口诀:**

> **有一个有力的官杀在,就不是专旺。**
> **化神不当令,就不化。**

---

## 本章要点

1. **专旺 = 日主极强,满盘同类,顺我;从格 = 日主极弱,满盘异类,顺人**。方向相反
2. 五格:**曲直、炎上、稼穑、从革、润下**
3. 成立关键:**全局无有力的官杀**
4. 喜忌:喜**比劫、印、食伤**;忌**官杀、财**
5. **最喜食伤顺泄** —— 不压制,给出口
6. **化格标准比从格还严**,「化神当令」卡掉大多数
7. **中和 ≠ 数量均匀,而是气的运转通畅**。顺专旺的势,就是它的中和
8. 专旺格成就高但不稳,**最怕破格运**
