# 第 29 章 · 妻子、父母、兄弟

> [← 上一章](./28-宫位与十神配六亲.md)　·　[目录](../README.md)　·　[下一章 →](./30-女命.md)

## 这章讲什么

**六亲的具体看法。** 承接上一章的立场:这一块可靠度最低,以下全部是**参考**,不是断语。

---

## 一、原文:真诠自己的保留

### 子平真诠 · 论妻子

> 大约依财官看法，而参以宫分，用神,**其理甚验,而看法则活**。
>
> ……然亦有**不验者**,……**其理甚微,不可执一而论**。

### 白话

大致按财官的看法,再参考宫位和用神,**道理挺灵验,但看法要活**。

**但也有不灵的时候**……**这里面的道理很微妙,不能死抱一条规矩来论。**

> **「亦有不验者」** —— 沈孝瞻自己承认这套东西不总是准。本章所有内容都在这句话的约束下。

---

## 二、妻(男命)

### 两个指标

| 指标 | 看什么 |
|---|---|
| **十神** | 正财(偏财为妾/父,不作正妻论) |
| **宫位** | **日支** |

### 参考判断

**财星层面:**

| 财星状态 | 参考含义 |
|---|---|
| 财有力、有情、不被冲克 | 妻贤,得力 |
| 财虚透无根 | 妻缘薄,或聚少离多 |
| 财被比劫夺 | 因人破财,或婚姻有第三方干扰 |
| **财多身弱** | **担不起**。妻强夫弱,或为妻所累 |
| 财被合走 | 姻缘有变数 |

**日支层面:**

| 日支状态 | 参考含义 |
|---|---|
| 日支为喜神 | 婚姻是助力 |
| 日支为忌神 | 婚姻是负担 |
| 日支被冲 | 婚姻动荡 |
| 日支被合 | 有牵绊,或早有对象 |

### 真诠的一条具体说法

> **财为妻,而妻为财所出,故财旺则妻贤,财衰则妻弱。**

**白话**:财代表妻,财旺妻贤,财衰妻弱。

> 但注意加上第 11 章的修正:**财「旺」和财「强」是两回事。** 财得令但孤立无援,不算真旺。

## 三、夫(女命)

### 两个指标

| 指标 | 看什么 |
|---|---|
| **十神** | **正官**(七杀为偏,不作正夫论) |
| **宫位** | **日支** |

### 参考判断

| 官星状态 | 参考含义 |
|---|---|
| 官清有力,不混杀 | 夫得力,婚姻正 |
| **官杀混杂** | 感情复杂,或多次婚姻 |
| 官被伤官克 | 婚姻受冲击(伤官克官) |
| 官虚透无根 | 夫缘薄 |
| 官被合走 | 「**夫星被合去**」——见下 |
| 无官无杀 | 需从整体气势看,不必然不利 |

### 真诠的一段(第 2 章引过)

> 女以官为夫，而被他干合去，官夫岂能爱其妻乎？
>
> ……惟壬在月上，而年丁合之，日干之丁，反不能合，**是以己之夫星,被姊妹合去**。

**白话**:女命以官为夫。如果夫星被别的天干合走了,这个丈夫还怎么爱你?

但如果是**日主自己去合**夫星,那叫**夫妻相亲,情分更密**。

只有当夫星在月干、被年干的同类合走,日主自己合不着——**这才叫夫星被姐妹合去**。

> **同样是「合」,日主自己合是好事,被别人合走才是坏事。** 这一条区分很多书都讲错。

## 四、父母

### 指标

| 六亲 | 十神 | 宫位 |
|---|---|---|
| **母** | 正印 | **月柱** |
| **父** | 偏财 | **月柱**(或年柱) |

### 参考判断

| 状态 | 参考含义 |
|---|---|
| 印为喜神且有力 | 得母荫 |
| 印为忌神 | 母缘或有妨碍 |
| 偏财为喜神且有力 | 得父助 |
| **月柱为喜神** | 出身、父母对我有助 |
| **月柱为忌神** | 出身条件不利,或早年不顺 |
| 月柱被冲 | 早年动荡、离乡 |

### 一个更可靠的用法

**看月柱整体是喜是忌,比看印和偏财单独判断可靠。**

理由和第 28 章一样:**宫位链条短,十神链条长。**

> 尤其「偏财为父」这条,是经过两次推论得来的,可靠度最低。

## 五、兄弟姐妹

### 指标

| 十神 | 宫位 |
|---|---|
| 比肩、劫财 | **月柱** |

### 参考判断

| 状态 | 参考含义 |
|---|---|
| 比劫为喜神(身弱) | 得兄弟朋友之助 |
| **比劫为忌神(身旺,或财格)** | **被兄弟朋友所累** |
| 比劫多而有力 | 兄弟多,或竞争多 |
| 比劫被官杀制 | 兄弟受制,或自己在群体中受压 |

### 一个实用的引申

**比劫在现代更常对应「同辈、合伙人、竞争者」,不只是亲兄弟。**

- 财格身旺 → 比劫夺财 → **合伙容易出问题**
- 身弱财旺 → 比劫帮身 → **合伙反而好**

> 这个引申比「有几个兄弟」的判断可靠得多,因为它直接建立在**喜忌**上,不依赖「比劫 = 兄弟」这个跳跃。

## 六、子女

### 指标

| | 十神 | 宫位 |
|---|---|---|
| **男命** | 官杀(七杀=子,正官=女) | **时柱** |
| **女命** | 食伤(伤官=子,食神=女) | **时柱** |

### 参考判断

| 状态 | 参考含义 |
|---|---|
| 时柱为喜神 | 子女得力,晚年安 |
| 时柱为忌神 | 子女缘薄,或晚年操心 |
| 时柱被冲 | 晚年动荡 |

### 真诠《论妻子》的态度

> 至于**子息之说**,……**大约以时为主**,而参之以用神。

**白话**:子女这一块,**大致以时柱为主**,再参考用神。

> **连真诠自己都是「以宫位为主」**,而不是以十神为主。这印证了本书的立场:**宫位比十神可靠。**

---

## 七、一个统一的、更可靠的方法

放弃「某十神 = 某人」的映射,改用这个:

```
第 1 步  确定全局喜忌(第 5 部)

第 2 步  看四个宫位各自是喜是忌
        年柱 = 祖上/早年
        月柱 = 父母兄弟/青年
        日支 = 配偶/中年
        时柱 = 子女/晚年

第 3 步  喜神所在的宫位 → 这方面是助力
        忌神所在的宫位 → 这方面是阻力
        被冲的宫位     → 这方面动荡
        被合的宫位     → 这方面有牵绊

第 4 步  十神只作补充参考,不单独下断语
```

### 为什么这样更可靠

**因为它只用了一次跳跃**(宫位 → 人生领域),而十神法要两次以上(十神 → 六亲 → 吉凶)。

**每一次跳跃都是误差来源。跳得越少越稳。**

---

## 八、一个必须强调的边界

**不要用六亲判断去做现实决定。**

这套模型:

- 没有可检验的实证基础
- 五本古籍自己就不统一
- 沈孝瞻本人说「亦有不验者」「其理甚微」

**它能提供的是一种「结构性的自我观察」——比如「我的财星是忌神,所以我在金钱上容易失控」——而不是关于具体某个人的判断。**

> 把它当理解自己的一个角度,不要当成关于别人的结论。

## 本章要点

1. **沈孝瞻自己说「亦有不验者」「其理甚微,不可执一而论」** —— 本章全部内容在这句话约束下
2. **男看妻**:正财 + 日支;**女看夫**:正官 + 日支
3. **夫星被日主自己合是好事(夫妻相亲),被别人合走才是坏事**
4. 父母看**月柱整体**比看印/偏财可靠;子女看**时柱**——真诠自己也是「以时为主」
5. **比劫在现代更常对应同辈、合伙人**,这个引申比「几个兄弟」可靠
6. 统一方法:**看四个宫位各自是喜是忌**,十神只作补充
7. 理由:**跳跃越少越稳**。宫位一次跳跃,十神两次以上
8. **不要用六亲判断做现实决定**——这超出了模型能承担的范围
