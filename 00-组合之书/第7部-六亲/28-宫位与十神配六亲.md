# 第 28 章 · 宫位与十神配六亲

> [目录](../README.md)　·　[下一章 →](./29-妻子父母兄弟.md)

## 这章讲什么

**两套系统看六亲:宫位(位置)和十神(关系)。** 两套要合起来看,单用一套会得出错误结论。

---

## 一、原文

### 子平真诠 · 论宫分用神配六亲

> 人有六亲，配之八字，亦存于命。
>
> 其由**宫分配之**者，**年月日时,自上而下,祖父妻子,亦自上而下**,以地相配,适得其宜,不易之位也。
>
> ……其由**用神配之**者，则**正印为母,身所自出**,取其生我也;
>
> 若偏财受我克制，何反为父？盖父者，全我之身,与我相配者也,而印绶为母,则偏财是父明矣。
>
> ……**至于扶抑之外,又有宫分之说**,……**二者不可偏废**。

### 白话

人有六亲,配到八字里,也都在命中。

**按宫位配**:年月日时从上到下,对应祖、父、妻、子,也是从上到下。**按位置相配,正好合适,这是固定的位置。**

**按用神(十神)配**:
- **正印是母**,因为我从她那里生出来,取的是「生我」
- 偏财受我克制,为什么反而是父?因为**父是与母相配的那个人**。既然印绶是母,那么偏财就是父

最后一句最关键:**除了用十神,还有宫位之说,两者不可偏废。**

---

## 二、宫位系统

| 柱 | 宫位 | 代表的人 | 代表的年龄段 |
|---|---|---|---|
| **年柱** | 祖上宫 | 祖父母、家族根基 | 1-16 |
| **月柱** | 父母宫 | 父母、兄弟 | 17-32 |
| **日柱** | 天干=自己<br>地支=**夫妻宫** | 配偶 | 33-48 |
| **时柱** | 子女宫 | 子女、下属 | 49- |

### 宫位的用法

```
看某个六亲 → 先看他的宫位
宫位的字是喜神     → 这个六亲对我有助
宫位的字是忌神     → 这个六亲对我不利
宫位被冲          → 这方面动荡
宫位被合          → 这方面有牵绊
```

### 日支为什么是夫妻宫

**日柱天干是自己,天干坐在地支上,最贴身的位置就是配偶。**

这是宫位法里最有说服力的一条,也是实务中最常用的。

---

## 三、十神系统

| 六亲 | 十神(男) | 十神(女) | 逻辑 |
|---|---|---|---|
| **母** | 正印 | 正印 | 生我者 |
| **父** | 偏财 | 偏财 | 与母相配者(克母者) |
| **兄弟姐妹** | 比肩、劫财 | 比肩、劫财 | 同我者 |
| **妻** | **正财** | — | 我克者,我所支配 |
| **夫** | — | **正官** | 克我者,管我者 |
| **儿子** | **七杀** | **伤官** | 见下 |
| **女儿** | **正官** | **食神** | 见下 |

### 为什么父是偏财

这是最反直觉的一条。真诠的推理:

```
印是母(生我者)
父是与母相配的人
克印的是财
偏财(阳克阳/阴克阴,同性)为父
```

**「盖父者,全我之身,与我相配者也。」**

> 逻辑是自洽的,但它建立在「印为母」这个前提上。

### 子女为什么男女不同

**男命**:我克者为财(妻),**财所生者为官杀** → 官杀为子女。

**女命**:我生者为食伤 → 食伤为子女(自己生的)。

> 女命看子女用食伤,是全部六亲配法里逻辑最直接的一条。

---

## 四、两套系统怎么合用

### 原文的态度

> **二者不可偏废。**

### 具体做法

```
第 1 步  用十神看"这个六亲的性质"
        例:男命看妻,找正财
        正财有力有情 → 妻贤能
        正财被冲被克 → 妻多波折

第 2 步  用宫位看"这方面的实际境遇"
        例:看日支
        日支为喜神 → 婚姻得力
        日支被冲   → 婚姻动荡

第 3 步  两者一致 → 结论明确
        两者矛盾 → 需要细辨
```

### 矛盾时怎么办

| 情况 | 参考判断 |
|---|---|
| 十神好,宫位坏 | 对象条件不错,但相处不顺 |
| 十神坏,宫位好 | 对象一般,但相处安稳 |
| 都好 | 佳 |
| 都坏 | 不佳 |

> **这是参考性的,不是定论。** 六亲判断在整个命理里可靠度最低,原因见下。

---

## 五、必须说的一句话:六亲判断可靠度最低

**这是本书的立场,要说清楚。**

### 三个理由

**1. 十神配六亲的逻辑链条太长**

「印为母 → 克印者为父 → 偏财为父」,每一步都是推论,推论叠推论,误差累积。

**2. 缺乏可验证性**

「正财代表妻」——但一个人的八字里正财强弱,和他妻子实际是什么人,**没有可检验的对应关系**。同一个八字的人,妻子千差万别。

**3. 五本古籍自己就不统一**

| 书 | 男命子女看什么 |
|---|---|
| 子平真诠 | 官杀 |
| 三命通会 | 官杀,但也讲时柱 |
| 部分后世书 | 直接看时柱 |

**连基本配法都没统一,说明这套东西没有稳定的实证基础。**

### 沈孝瞻自己的态度

真诠《论妻子》里有一句:

> **其理甚微,不可执一而论。**

**白话**:这里面的道理很微妙,**不能死抱着一条规矩来论。**

> 他自己也知道六亲这块不牢靠。

### 本书建议

```
格局、用神、行运   → 可以下较明确的判断
六亲              → 只作参考,不下断语
```

**尤其不要用六亲判断去影响现实决定**(该不该结婚、该不该生孩子)。这超出了这套模型能承担的范围。

---

## 六、一个相对可靠的用法

**如果一定要用,最可靠的是这一条:**

> **看日支(夫妻宫)是喜神还是忌神。**

理由:
- 它只用一个宫位,链条最短
- 日支是日主最贴身的字,对全局影响最直接
- **不需要经过「十神代表某人」这个跳跃**

| 日支 | 参考含义 |
|---|---|
| 喜神,有力 | 婚姻对命主是助力 |
| 忌神,有力 | 婚姻对命主是负担 |
| 被冲 | 这方面容易动荡 |
| 被合 | 这方面有牵绊 |

**其余的六亲判断,链条越长越不可靠。**

## 五书对照

| 书 | 立场 |
|---|---|
| **子平真诠** | 《论宫分用神配六亲》《论妻子》,**明确「二者不可偏废」**,也承认「其理甚微」 |
| **三命通会** | 六亲论述**最多最细**,大量断语 |
| **渊海子平** | 六亲配法的早期来源 |
| **滴天髓** | **《夫妻》《子女》《父母》《兄弟》四章专论**,讲得最活,强调看整体配合 |
| **穷通宝鉴** | 不谈 |

### 滴天髓的态度

任铁樵在《夫妻》章里强调:**不能只看财官这一个字,要看它在全局的位置和作用。**

> 这和本书「链条越长越不可靠」的立场是一致的:**六亲要放回全局看,不能孤立地拎出一个十神下断语。**

## 本章要点

1. **两套系统**:宫位(位置)和十神(关系),**二者不可偏废**
2. 宫位:年=祖上、月=父母、**日支=夫妻宫**、时=子女
3. 十神:印=母、**偏财=父**(克印者)、男命财=妻、女命官=夫
4. 子女:**男看官杀,女看食伤**
5. 两套矛盾时可细辨,但**结论是参考性的**
6. **六亲判断在整个命理里可靠度最低**:链条太长、缺乏可验证性、各书不统一
7. 沈孝瞻自己也说「**其理甚微,不可执一而论**」
8. 相对可靠的只有一条:**看日支是喜神还是忌神**——链条最短
